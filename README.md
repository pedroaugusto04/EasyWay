# EasyWay

EasyWay is a real-time ride coordination application that allows drivers to create routes and passengers to share their locations.
The system tracks the driver’s position in real time and automatically notifies passengers when the driver is approaching.

##  Real-Time Driver Tracking

Passengers can track the driver's location in real time using WebSockets.

Drivers can choose whether or not to notify specific passengers along the route.

When enabled, passengers receive a **push notification** once the driver reaches a predefined distance.
